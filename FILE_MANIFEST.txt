USAGE SUMMARY
================================================================================

PHASE 1 - QUICK DIAGNOSTICS (15 minutes):
  1. cd diagnostics
  2. sqlplus user/pass@db @db_performance_check.sql > ../reports/db_check.txt
  3. sqlplus user/pass@db @apex_metadata_check.sql > ../reports/apex_check.txt
  4. Review output files

PHASE 2 - APPLY OPTIMIZATIONS (30 minutes):
  1. Update ORDS: cp config-templates/ords-defaults.xml $ORDS_CONFIG/
  2. Update Tomcat: cp config-templates/jvm-tuning.sh $CATALINA_HOME/bin/setenv.sh
  3. Run optimizations: sqlplus user/pass@db @optimizations/apex_performance_optimization.sql
  4. Restart services

PHASE 3 - CONTINUOUS MONITORING:
  1. ./diagnostics/automated_monitoring.sh -i 300 -o ./monitoring_output &
  2. Monitor: tail -f monitoring_output/monitoring_*.log
